# Локальный канбан отзывов

Запуск из корня проекта:

```sh
python3 4-prototyping/research-board/server.py
```

Открыть http://127.0.0.1:8766. Зависимостей нет, достаточно Python 3.

Доска читает 40 отзывов из `1-research/open-research.md` и метаданные из `1-research/sources.json`. Цитаты и ссылки берутся из исследования без переписывания.

- «Новая группа» создаёт колонку. Название редактируется сразу, позднее — двойным нажатием по названию или через меню.
- Карточки можно перетаскивать между колонками и менять их порядок. В раскрытом контексте есть выбор группы — для клавиатуры и телефона.
- Меню колонки позволяет менять цвет, порядок и удалять группу. При удалении карточки возвращаются в «Без группы».
- «Контекст и заметка» раскрывает полный пересказ, автора и личную заметку.
- «Отменить» возвращает предыдущее действие текущего сеанса.
- «Скачать доску» сохраняет группы, расположение и заметки в JSON. «Загрузить» восстанавливает их; действие можно отменить.

Раскладка сохраняется на диске в `1-research/board-state.json` и дополнительно в localStorage браузера. Сервер доступен только на этом компьютере. Исходная таблица не изменяется. История перемещений и переименований хранится в `activity` для совместного разбора решений; она описывает действия, но не доказывает причины выбора группы.
